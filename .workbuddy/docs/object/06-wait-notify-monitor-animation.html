为什么 wait 必须膨胀？（synchronizer.cpp:545）

      

        注释原话："must use heavy weight monitor to handle wait()"。
      

      
    
        
  • 轻量锁（lock=00）：mark word + 栈帧 Lock Record，没有挂起线程的地方——线程只能自旋。
    • 
        
  • 重量级锁（lock=10）：mark word 指向 ObjectMonitor，内部有 Owner / cxq / _EntryList / _WaitSet 完整队列，能 park 线程。
    • 
        
  • 所以 wait 语义（挂起等待 + 可被唤醒）只有膨胀后才有实现载体。
    • 
        
  • notify 的快速路径反过来利用这一点：对象还是快速锁 → 有 wait 早膨胀了 → 必然没 waiter → 直接 return。
    •
