Cloneable 检查的两个隐藏点

      
    
        
  • 所有数组都算 Cloneable（JLS 20.1.5）——int[].clone() 永远合法。
    • 
        
  • j.l.r.Reference 子类不可克隆（880 行）：reference_type() != REF_NONE 一律抛
          CloneNotSupportedException —— 否则克隆会破坏引用语义。
    • 
        
  • is_cloneable() 是类加载时算好的标志位，864-873 行 ASSERT 专门校验。
    • 
      

      

        value class（Valhalla）没有 identity，clone 直接返回自身（885-889）——对应总览里类注释
        "value class 的 clone 可能与原对象不可区分"。
